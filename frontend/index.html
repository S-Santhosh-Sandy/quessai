Architecture — Strands Multi-Agent System
Supervisor Agent — orchestrates state machine: RECEIVED → CLASSIFIED → EXTRACTED → NORMALIZED → VALIDATED → PUSHED → COMPLETE
Agent 1 · Ingestion & Classification — python-magic + openpyxl + PyMuPDF + pandas. Assigns Job ID.
Agent 2 · Document Extraction — AWS Bedrock Claude Sonnet via Anthropic SDK. Structured prompt → JSON with confidence scores.
Agent 3 · Field Normalization — ISO 8601 dates, decimal hours, QZone legend codes (WO/PL/MISSING), canonical IDs.
Agent 4 · Validation + Human Review — business rules: <24h/day, <60h/week, pay period, missing days. <0.90 conf → review queue.
Agent 5 · QZone Integration — async httpx REST push, OAuth2 Bearer, batch 50 records, exponential backoff retry.
